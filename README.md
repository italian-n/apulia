## 📖 O projektu

Jednostránkový (single-page) prodejní web pro **exkluzivní distribuci prémiového olivového oleje z Apulie (Itálie)** na českém trhu. Web slouží jako digitální vizitka a prodejní kanál — objednávky se zpracovávají přímo přes WhatsApp.

**Produkty:**
| Produkt | Balení | Cena |

| Extra Panenský Olivový Olej | 5 L | 1 290 Kč |
| Olivový Olej Vergine ⭐ nejprodávanější | 10 L | 1 690 Kč |
| Olivový Olej na Smažení | 10 L | 1 490 Kč |

## ✨ Funkce webu

- 🌍 **8 jazykových verzí** — čeština (výchozí), angličtina, ukrajinština, ruština, italština, němčina, polština, slovenština
- 💬 **Objednávky přes WhatsApp** — bez nutnosti registrace nebo košíku
- 🍪 **GDPR cookie banner** s Google Consent Mode — reklamní sledování se aktivuje až po souhlasu návštěvníka
- 📊 **Google Ads conversion tracking** — sledování kliknutí na tlačítko "Koupit" u každého produktu
- 📄 **Certifikáty a laboratorní rozbory** — ke stažení přímo z webu (technické listy, analýza COI/EU norem)
- 📱 **Plně responzivní** — optimalizováno pro mobil, tablet i desktop, včetně touch-friendly ovládání
- 🎥 **Video prezentace produktů** přímo na kartách jednotlivých olejů
- ⚡ **Statický web** hostovaný na GitHub Pages — rychlé načítání, žádný backend

## 🛠️ Technický stack

- Čisté **HTML / CSS / JavaScript** (bez frameworků — maximální rychlost načítání)
- Vlastní i18n systém pro přepínání jazyků
- Google Tag (`gtag.js`) s Consent Mode v2 pro GDPR compliance
- JSON-LD strukturovaná data (Schema.org) pro SEO
- Hosting: **GitHub Pages** + vlastní doména `apuliaoliveoil.cz`
